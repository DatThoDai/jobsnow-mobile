# JobsNow Mobile - UI UX Pro Max

## Design Intent
- Pattern: editorial hero + card curation
- Mood: premium, calm, high-contrast
- Motion: subtle fades and lifts, 200-300ms
- Accessibility: maintain 4.5:1 contrast for text

## Color Palette
- Primary: #1F4B9D
- Accent: #E1B46B
- Background: #F4F2EF
- Surface: #FFFFFF
- Text Primary: #121417
- Text Secondary: #5A6472
- Border: #E2DDD4

## Typography
- Display: Baskerville (iOS) / serif (Android)
- Body: Avenir Next (iOS) / sans-serif-condensed (Android)

## Components
- Cards: rounded 16-24, soft borders, gentle shadows
- Buttons: pill shape, uppercase labels, strong primary
- Search: elevated pill with soft border
- Avatar: accent ring with initials fallback

## Layout Rules
- 20-24 horizontal padding
- 16-24 vertical rhythm
- Hero copy max width ~320

## Avoid
- Neon or purple gradients
- Busy background textures
- Emoji icons as UI controls
